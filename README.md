# Career Mail Studio

A standalone browser project based on your original `Job.html`, upgraded with:
- Modern responsive dark UI
- Job email templates
- Live message preview
- PDF and Word file selection/listing
- Copy message and launch default mail app

## Run
Open `index.html` in Chrome/Edge. No installation or server is required.

## Important attachment limitation
This is a browser-only project. Browsers do not allow a webpage to attach chosen local files to a `mailto:` message automatically. The app displays selected PDF/Word files, then opens your email app; attach those files manually there.
